MISSION EARTH

Forecasting next-day wildfire risk from a cheap weather station.

The official early-warning system — Canada's Fire Weather Index — needs a calibrated station and a trained analyst to hand-compute six chained fuel-moisture codes. Most under-resourced Mediterranean districts have neither. This project asks: can four readings any low-cost station already has — temperature, humidity, wind, rain — plus a memory of recent dryness, get close enough to matter?

Feature engineering — 01

Fire risk isn't today's weather — it's the memory of dry days.

DryDays · Rain_sum3 · HeatDryIdx
What you're seeing

The licensed FWI fuel-moisture codes were banned from the feature set — keeping them would flatter a model nobody in an under-resourced district could actually run, since they're the expert system's own output. So the notebook rebuilds their "memory" from raw sensor lags: DryDays, 3-day rolling temperature/humidity, and rainfall sums. Boxplots confirm these separate fire from non-fire days cleanly — direct evidence the memory carries real signal.

Why this visual

A timeline of accumulating dryness that resets the instant it rains mirrors exactly what the DryDays feature computes in code — a viewer grasps the idea in one glance, instead of reading a formula for a rolling-window mean.

Notebook · EDA 4 DryDays and HeatDryIdx both separate fire from non-fire days on real data — the concept above isn't just illustrative.

Operating point — 04

At threshold 0.52, the model never misses a fire.

60 September test days
What you're seeing

The alert threshold isn't the default 0.5 — it's tuned on training folds to reflect a resource-constrained patrol budget. At 0.52: recall = 1.00 (all 23 September fire-days caught), precision = 0.82 (5 false alarms across 60 days), and zero missed fires. In this domain a false alarm costs a wasted patrol; a missed fire costs a fire.

Why this visual

A 60-cell waffle literalises "out of 60 real test days, this many of each outcome" — more honest for a safety-critical result than a bare percentage, and the dashed, empty missed-fire slot is a visual promise the numbers back up.

How it's built — 05

Three different learners vote through a meta-learner.

Stacking ensemble
What you're seeing

The winning model is a stacking ensemble: logistic regression, random forest, and XGBoost each produce an out-of-fold probability during 5-fold cross-validation, and a final logistic-regression meta-learner combines them — so the meta-model never sees a prediction made on data it was trained on.

Why this visual

A block-and-arrow schematic is the plain, standard way to show data flow through a pipeline — the point here is structural, not comparative, so no embellishment beyond labelling the leak-prevention step was needed.
